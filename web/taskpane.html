Excel Formula Add-in

Translate with worksheet formulas

This add-in registers custom functions in Excel, so you can translate directly from formulas instead of clicking a button in a task pane.

Use these formulas

=XLT.TRANSLATE(A2,"de") =XLT.TRANSLATE(A2,"en","de") =XLT.TRANSLATE_RANGE(A2:B10,"fr")
Default backend
LM Studio via the local proxy and the currently loaded model
Local add-in host
https://localhost:3000
