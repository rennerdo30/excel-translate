## What it is

Excel Translate is an Office Add-in for **Excel for Mac** that registers two custom worksheet
functions in the `XLT` namespace:

```text title="Worksheet formulas"
=XLT.TRANSLATE(A2,"de")
=XLT.TRANSLATE(A2,"en","de")
=XLT.TRANSLATE_RANGE(A2:B10,"fr")
```

The formulas call a small local HTTPS host written with the Python standard library. That host
serves the add-in's static files to Excel and proxies translation requests to
[LM Studio](https://lmstudio.ai/docs/developer/core/server)'s OpenAI-compatible local API, using
whichever model you have loaded there.

## How the pieces fit

1. Excel loads the add-in from `https://localhost:3000` using a sideloaded `manifest.xml`.
2. `web/functions.js` implements `TRANSLATE` and `TRANSLATE_RANGE` and `POST`s to `/api/translate`.
3. `scripts/dev_server.py` receives that request, builds a translation prompt, and calls LM Studio's
   `/v1/chat/completions`.
4. The translated strings come back to the cell (or spill across a range).

See [Architecture](/excel-translate/guides/architecture/) for the full request path, and
[Formula Reference](/excel-translate/guides/formulas/) for argument semantics.

## Requirements

- macOS with Excel for Mac that supports the Custom Functions runtime (`CustomFunctionsRuntime` 1.1)
- Python 3.12+ (or Docker, which is the documented default path)
- LM Studio with its local server running and a model loaded
- A self-signed `localhost` certificate that you generate yourself — see
  [Installation](/excel-translate/getting-started/installation/)
